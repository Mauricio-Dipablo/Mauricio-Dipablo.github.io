¿Quién es Mauricio en una frase?
Un Data Analyst y BI Developer apasionado por limpiar datos desordenados y convertirlos en historias visuales, dashboards interactivos y modelos precisos para la toma de decisiones.
¿Qué tipo de problemas resuelves?
Todo aquello cuya respuesta se encuentra oculta en los datos: Desde el análisis de bases de datos inmensas y la automatización de reportes (ETL), hasta mapas de logística (Kepler.gl) y el entrenamiento de modelos de Machine Learning para detección de fraudes o anomalías.
¿Con qué herramientas trabajas a diario?
Mi stack principal es SQL, Python (Pandas, Scikit-learn, Seaborn, Matplotlib), Excel y Power BI. También manejo Azure, control de versiones (Git) y software CAD (AutoCAD/SolidWorks).
¿Cómo abordas un nuevo proyecto analítico?
Todo empieza con la pregunta de negocio. Luego audito y limpio los datos (EDA), defino un modelo relacional o predictivo, y finalmente construyo la visualización para responder: qué pasó, por qué pasó y qué hacer.
¿Qué tipo de roles o posiciones estás buscando?
Busco roles como Data Analyst, BI Developer o posiciones relacionadas. Estoy abierto a esquemas de trabajo full-time y parcial, modalidad remota.
¿Cómo integras la Inteligencia Artificial en tu flujo de trabajo?
Llevo 4 años utilizando IA para potenciar mi productividad, optimizar código y resolver problemas complejos. Aplico técnicas de prompt engineering para obtener resultados precisos de forma eficiente, priorizando un uso responsable y optimizando al máximo el consumo de recursos de cada modelo.
